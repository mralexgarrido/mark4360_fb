# Facebook Simulator Revamp: design review

The teaching objective is a faithful campaign-creation exercise that an instructor can evaluate. Students need realistic setup motions, contextual explanations, previews, practice publication, and an exportable record. Strategy and effectiveness belong to the instructor's grading process.

The revamp removes the earlier strength indicator and budget visualization. Required configuration is checked without scoring creative quality, predicting delivery, or generating scenario outcomes. The six objectives lead to represented conversion locations and performance goals, with destination-specific fields.

One campaign, one ad set, and one ad provide a manageable classroom workflow. Four illustrative image placements and carousel support show how the same creative can appear differently. Native modal dialogs, semantic labels, visible focus styles, and a narrow-screen preview address weaknesses in the former interface. Actual browser and assistive-technology checks remain necessary before making accessibility claims.

A versioned workspace supports browser saving, legacy migration, portable JSON backup, and separate draft/published settings. Dedicated HTML/print packets preserve settings, creative, explanations, and a clearly qualified local process record. These records support instructor review without becoming an automated assessment.
